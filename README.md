# Lock-in

A modern productivity and focus application featuring:
- **Focus Buddy**: Virtual companion and focus session tracking
- **Task Board**: Interactive task and session management
- **Study Rooms**: Video rooms and synchronized focus sessions
- **Analytics & Reports**: Visual reports and check-in history

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Routing**: TanStack Router
- **Styling**: Tailwind CSS
- **Backend**: Firebase

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
